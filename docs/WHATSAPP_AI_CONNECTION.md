# WhatsApp AI в Revora

## Что уже работает

Revora принимает сообщения WhatsApp Cloud API через защищённый webhook, разделяет
диалоги по номеру клиники и пациенту, предлагает ответ только из утверждённой базы
знаний и передаёт диалог человеку при жалобе, срочном симптоме, прямой просьбе
пациента или отсутствии подтверждённого ответа.

Контакты и тексты переписок хранятся в базе в зашифрованном виде. Входящие webhook
проверяются подписью Meta, повторная доставка одного сообщения не создаёт дубль.
Каждая клиника изолирована по `tenant_id`.

Режим по умолчанию — `draft`: ответ бота сохраняется как черновик и не уходит
пациенту. Автоматическую отправку можно включать только после тестового пилота.

## Бесплатное тестирование

1. Войти владельцем клиники в Revora.
2. Открыть **WhatsApp AI → База знаний**.
3. Загрузить `AMO CRM_Скрипты_v2.xlsx`.
4. Проверить строки и вручную одобрить безопасные ответы.
5. Открыть **Симулятор** и писать от имени пациента.

Симулятор не подключён к Meta и стоит 0 ₸. При `WHATSAPP_AI_PROVIDER=rules`
он не вызывает внешнюю языковую модель. Листы с рассылками, возвратами,
триггерами и акциями помечаются `human_only` и не могут стать автоматическими
ответами.

## Данные, которые понадобятся от WhatsApp Business

Секреты хранятся только на backend:

- `WHATSAPP_VERIFY_TOKEN` — случайная строка, которую мы задаём сами и указываем
  в Meta при создании webhook;
- `WHATSAPP_APP_SECRET` — App Secret приложения Meta;
- `WHATSAPP_ACCESS_TOKEN` — постоянный системный токен с минимальными правами
  WhatsApp;
- `WHATSAPP_DATA_KEY` — отдельная случайная строка длиной не менее 32 символов
  для шифрования пациентов и сообщений;
- `WHATSAPP_TENANT_SLUG` — slug клиники в Revora, например `test1`.

Callback URL:

`https://revora-api-bekarysibrashev.onrender.com/api/v1/webhooks/whatsapp`

В Meta нужно подписать webhook на поле `messages`. Несколько номеров
поддерживаются: Revora автоматически создаёт отдельный канал по
`phone_number_id` из каждого webhook.

Если клиника уже использует WhatsApp Business App, сначала нужно проверить
доступность официального режима Coexistence для её номера. Нельзя переносить или
отключать рабочий номер без резервного плана и письменного согласия клиники.

## Безопасный запуск

1. Подключить один тестовый номер, оставить `WHATSAPP_AI_AUTO_SEND=false`.
2. Проверить сценарии, цены, адреса, русский и казахский язык.
3. Провести пилот с администраторами: бот готовит черновики, человек отвечает.
4. Включить AI-провайдера и контролировать счётчик расходов.
5. Только после приёмки включить автоматическую отправку для безопасных FAQ.

Лимит `WHATSAPP_MONTHLY_BUDGET_KZT=10000` останавливает платные AI-вызовы после
достижения бюджета. Это не включает стоимость разговоров WhatsApp Cloud API:
она зависит от тарифов Meta и страны получателя.
