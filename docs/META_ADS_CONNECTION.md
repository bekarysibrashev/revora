# Подключение Meta Ads к Revora

## Что запросить у клиники

Не запрашивать логин, пароль, cookie или код двухфакторной аутентификации Facebook.

Клиника должна выдать отдельный доступ к рекламному аккаунту:

1. Открыть Meta Business Suite / Business Settings.
2. Добавить пользователя Revora или партнёра к нужному рекламному аккаунту.
3. Выдать минимальную роль для просмотра статистики — аналитик рекламного аккаунта.
4. Передать только ID рекламного аккаунта в формате `act_...`.

Если рекламный аккаунт не входит в Business Portfolio, владелец может добавить
отдельного пользователя в Ads Manager с ролью аналитика. Этот доступ можно
отозвать без смены пароля клиники.

## Что будет читать Revora

- кампании, группы объявлений и объявления;
- расходы, показы, охват, клики и даты;
- лиды и другие доступные рекламные результаты;
- UTM-метки и названия кампаний для сопоставления с лидами Revora.

На первом этапе Revora не получает право создавать, редактировать, запускать
или останавливать рекламу.

## Технический контур

1. Создать Meta Developer App, принадлежащий Revora.
2. Указать HTTPS callback URL backend Revora.
3. Подключать клинику через OAuth и запрашивать только разрешения чтения,
   необходимые Marketing API.
4. Хранить токен только на backend в зашифрованном виде; не отправлять его во
   frontend и не записывать в логи.
5. Проверять OAuth `state`, применять короткую сессию подключения и ротацию
   токенов.
6. Загружать статистику идемпотентно по ID рекламного аккаунта, кампании,
   дате и окну атрибуции.
7. Сохранять сырые ответы отдельно от нормализованных фактов для аудита и
   повторного расчёта.
8. Показывать дату последней синхронизации, ошибки и срок действия доступа.

## Что ещё необходимо до реализации OAuth

- Meta Business Portfolio Revora;
- Meta Developer App ID и App Secret;
- HTTPS callback URL;
- доступ приложения к Marketing API;
- ID рекламного аккаунта клиники;
- подтверждение владельца клиники в окне Meta OAuth.

App Secret и access token нельзя присылать в чат или хранить в репозитории:
они задаются секретами окружения на сервере.
