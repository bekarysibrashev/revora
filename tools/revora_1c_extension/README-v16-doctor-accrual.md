# Revora 1C extension v16

Версия `1.6.0.0` продолжает рабочий snapshot/operational pipeline v15 и
добавляет начисленную выручку в разрезе врачей.

Источник — подтвержденный диагностикой реальной базы регистр накопления
`Продажи`: измерения `СтруктурнаяЕдиница`, `Сотрудник` и ресурс `Стоимость`.
Разрез `doctor_revenue_accrual` отправляется только тогда, когда сумма строк
по врачам с точностью до 0.01 совпадает с официальным итогом штатного отчета
выручки. При несовпадении основной отчет продолжает синхронизироваться, а
недостоверный разрез не отправляется.

## Установка

1. Сделайте резервную копию конфигурации 1С.
2. Распакуйте `RevoraExtensionReady-v16-doctor-accrual.zip`.
3. В Конфигураторе откройте расширение `Revora`.
4. Выберите **Конфигурация → Загрузить конфигурацию из файлов…** и укажите
   папку, содержащую `Configuration.xml` из архива.
5. Выполните **Проверка модулей** и обновите конфигурацию базы данных.
6. Запустите короткую синхронизацию за 1–2 дня и проверьте столбец
   «Начислено» на странице «Врачи».

Семь прежних контрольных отчетов, дневные снимки, пациенты, врачи и записи
не удалены и продолжают отправляться тем же способом.
