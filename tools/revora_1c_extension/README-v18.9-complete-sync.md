# Revora 1.8.9 — совместимая структура официальной СКД

В v18.8 официальный процессор сформировал колонки, но штатная табличная
структура отчёта не дала строк в коллекции. v18.9 сохраняет параметры и отборы
официального отчёта, заменяет только структуру вывода на поддерживаемые
детальные записи и явно включает все поля основного набора данных.

Защитные условия сохранены: результат не заменит рабочие показатели, пока
одновременно не совпадут количество, выручка и цена без скидки и пока не будет
найден врач. Почасовая синхронизация остаётся выключенной.

## Проверка

1. Обновить расширение из распакованного
   `RevoraExtensionReady-v18.9-complete-sync.zip`.
2. Выполнить `Проверка модулей`.
3. Синхронизировать только `04.08.2026–05.08.2026`.
4. Прислать блок `Официальная СКД в коллекции значений`, включая строки
   `колонки` и `поля основного набора`.

Годовую синхронизацию до контрольной проверки не запускать.
