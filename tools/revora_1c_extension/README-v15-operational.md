# Revora 1.5.0 — первый операционный контур

Версия добавляет отдельную пакетную синхронизацию детальных данных, не меняя
формулы и структуру семи официальных контрольных отчётов.

Передаются:

- полный реестр пациентов: GUID, ФИО, SHA-256 телефона, источник, филиал,
  первый и последний визит, количество визитов, активность;
- врачи со специализациями;
- записи выбранного периода: пациент, врач, филиал, время, статус,
  первичность и наличие фактического приёма.

Открытые номера телефонов не передаются. Пакеты ограничены 200 строками на
стороне 1С и 500 строками на стороне API. Повторная отправка безопасна:
записи обновляются по стабильному GUID 1С.

## Порядок запуска

1. Сначала развернуть backend с endpoint
   `/api/v1/integrations/1c/operational-records/batch`.
2. Распаковать `RevoraExtensionReady-v15-operational.zip` в новую папку.
3. В Конфигураторе выбрать существующее расширение `Revora` и выполнить
   **Конфигурация → Загрузить конфигурацию из файлов**.
4. Выполнить **Проверку модулей**. При любой ошибке не нажимать F7.
5. После чистой проверки обновить конфигурацию базы и запустить ручную
   синхронизацию короткого периода.

Автоматический почасовой запуск намеренно будет включён только после успешной
ручной проверки этого потока на реальной базе клиники.
