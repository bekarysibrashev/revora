# Revora 1.8.8 — материализация строк официальной СКД

В v18.7 официальный процессор СКД корректно создал набор колонок, но строки
результата остались пустыми. v18.8 использует полный протокол вывода коллекции,
предписанный платформой 1С: начало вывода, последовательный вывод каждого
элемента результата и завершение вывода.

Защитные условия v18.7 сохранены: результат СКД не заменит рабочие показатели,
пока одновременно не совпадут количество, выручка и цена без скидки и пока в
результате не будет найден врач. Почасовая синхронизация остаётся выключенной.

## Проверка

1. Обновить расширение из распакованного
   `RevoraExtensionReady-v18.8-complete-sync.zip`.
2. Выполнить `Проверка модулей`.
3. Синхронизировать только `04.08.2026–05.08.2026`.
4. Прислать блок `Официальная СКД в коллекции значений` и нижнюю строку
   `разрезы построены на источнике`.

Годовую синхронизацию до этой контрольной проверки не запускать.
