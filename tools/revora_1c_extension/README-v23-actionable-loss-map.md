# Revora 2.3 — карта потерь по пациентам, а не по отменам

## Что меняется

Карта потерь перестаёт считать каждую отменённую запись отдельным пациентом.
После установки одна карточка соответствует одному пациенту с проверенным номером:

- повторные отмены одного пациента не создают дубли;
- поздняя реальная запись переводит карточку в «Уже записались»;
- только отмены и неявки с номером, пришедшим из 1С, можно передать сотруднику в работу;
- номер передаётся из 1С только по HTTPS, хранится в Revora в зашифрованном виде и показывается только авторизованным сотрудникам Revora.

Это не называет 443 отмены «443 потерянными людьми»: сначала Revora объединяет события человека, исключает тех, кто вернулся, и оставляет проверяемую очередь для контакта.

## Важно перед установкой

В Render у API-сервиса добавьте переменную окружения `PATIENT_DATA_KEY`: случайная строка длиной не менее 32 символов. Не меняйте её после первой синхронизации: ею зашифрованы номера, и при замене старые номера нельзя будет расшифровать для интерфейса.

После сохранения переменной дождитесь успешного деплоя API. Ключ не вставляется в 1С и никогда не должен попадать в переписку, журнал или Git.

## Установка

1. В 1С откройте **Конфигуратор → Конфигурация → Расширения конфигурации → Загрузить из файла**.
2. Выберите `RevoraExtensionReady-v23-actionable-loss-map.zip`.
3. Выполните **Конфигурация → Проверить** и сохраните расширение.
4. В пользовательском режиме откройте **Revora → Синхронизация с Revora** и запустите синхронизацию за нужный период. Для первой проверки возьмите последние 3 месяца.
5. Откройте **Карта потерь** и нажмите **Пересчитать карту**.

## Критерии готовности

- синхронизация завершается без ошибки `PATIENT_DATA_KEY`;
- в карте потерь у карточек, которые можно вернуть в работу, виден номер телефона;
- одна карточка не дублируется из-за нескольких отмен;
- пациенты с последующей записью показаны в блоке «Уже записались» либо исключены из очереди;
- число «Требуют контакта» не интерпретируется как число всех отмен в 1С.

Если в карте нет номеров сразу после установки, выполните ещё одну синхронизацию: старые снимки содержали только необратимый хэш номера, из него номер восстановить невозможно.
