# Revora 1.5.0.1 — operational r2

Исправлена совместимость с синтаксисом серверного модуля платформы клиники:
создание `Запрос` и его выполнение разделены на отдельные операторы.

Остальной операционный контур и семь официальных отчётов не изменялись.

Установите `RevoraExtensionReady-v15-operational-r2.zip` через
**Конфигурация → Загрузить конфигурацию из файлов**, затем обязательно
выполните **Проверку модулей** до нажатия F7.
