# Revora 1.8.7 — единый официальный источник начисленной выручки

## Что исправляет эта сборка

Диагностика v18.6 доказала, что ограничение прав (RLS) не является причиной:
обычный и привилегированный запросы дали один и тот же неполный результат.
v18.7 больше не пытается воспроизвести экранный отчет выполнением одного текста
запроса. Она программно выполняет официальный отчет `ОказанныеУслугиПоВрачу`
целиком штатным процессором СКД и получает его результат в `ДеревоЗначений`.

Этот результат становится источником показателей клиники и разрезов по врачам
только если в одном прогоне одновременно выполнены четыре условия:

1. количество услуг совпало со строкой ИТОГО;
2. начисленная выручка совпала со строкой ИТОГО;
3. цена без скидки совпала со строкой ИТОГО;
4. в результате действительно найден хотя бы один врач.

Если хотя бы одно условие не выполнено, новые данные не подменяют рабочие
показатели. В окне синхронизации будут показаны реальные колонки, числа и текст
ошибки — расхождение не маскируется.

Почасовое регламентное задание в этой сборке по-прежнему выключено.

## Установка и единственная контрольная проверка

1. В Конфигураторе откройте `Конфигурация → Расширения конфигурации`.
2. Выберите `Revora`.
3. Выполните `Конфигурация → Загрузить конфигурацию из файлов…` и укажите
   распакованную папку из `RevoraExtensionReady-v18.7-complete-sync.zip`.
4. Выполните `Конфигурация → Проверка модулей`.
5. Если ошибок нет, примените изменения и запустите 1С:Предприятие.
6. В Revora выполните ручную синхронизацию строго за тот же период:
   `04.08.2026–05.08.2026`.
7. Скопируйте или сфотографируйте блок
   `Официальная СКД в коллекции значений`.

Успешный итог содержит строки:

- `все инварианты сошлись и есть врач: да`;
- `РЕЗУЛЬТАТ ПРИНЯТ`;
- `разрезы построены на источнике: официальная СКД`;
- расхождение начисленной выручки по врачам с итогом клиники — `0,00`.

До этого контрольного прогона синхронизацию за год запускать не нужно: сначала
проверяется формула на двух днях, затем тем же кодом безопасно выгружается год.
