# Revora 1.9.0 — одна установка, полный контрольный прогон

Эта сборка заменяет последовательность однофакторных диагностик одним прогоном.
За одну синхронизацию она сравнивает обычный запрос, запрос без RLS, исходную
структуру СКД, совместимую детальную структуру СКД и официальный экранный
табличный результат.

В окно выводятся все поля основного набора, тип исходной структуры, количество
строк и финансовые итоги обеих стратегий СКД, а также обезличенный профиль
первых 30 и последних 15 строк экранного отчёта. Профиль содержит координаты и
числа, но скрывает произвольный текст, поэтому ФИО пациентов и врачей туда не
попадают.

Ни одна экспериментальная стратегия не меняет рабочие показатели, пока
одновременно не совпадут количество услуг, начисленная выручка и цена без
скидки и не будет найден врач. Почасовая синхронизация выключена.

## Единственная проверка

1. Обновить расширение из распакованного
   `RevoraExtensionReady-v19.0-one-pass-sync.zip`.
2. Выполнить `Проверка модулей`.
3. Синхронизировать `04.08.2026–05.08.2026`.
4. Прислать весь текст результата. Если он не помещается на скриншотах,
   выделить текст в поле результата и скопировать его сообщением.

v18.9 отдельно устанавливать не нужно. Годовую синхронизацию пока не запускать.
