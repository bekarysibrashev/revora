# Revora 1.5.0.2 — operational r3

Исправлена runtime-совместимость преобразования нормализованного телефона в
двоичные данные для SHA-256. Вместо отсутствующего у `ПотокВПамяти` метода
`ПолучитьДвоичныеДанные()` используется штатный метод платформы
`ЗакрытьИПолучитьДвоичныеДанные()`.

Открытый телефон по-прежнему не отправляется. Остальной операционный контур и
семь официальных отчётов не изменялись.
