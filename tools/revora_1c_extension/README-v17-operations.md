# Revora 1C extension v17

Версия `1.7.0.0` — единая актуальная сборка. Устанавливать промежуточную v16
перед ней не требуется.

В сборку входят все возможности v15 и v16:

- семь контрольных отчетов и дневные снимки;
- полный реестр пациентов с SHA-256 хешами телефонов;
- врачи и специальности;
- записи за выбранный период;
- начисленная выручка по врачам из регистра `Продажи`, только после сверки
  разреза с официальным итогом клиники;
- признанные расходы за выбранный период из проведенных документов `Затраты`.

Расходы передаются как нормализованные `expense_fact` с GUID документа,
датой, филиалом, статьей и суммой. Банковские переводы и выплата зарплаты не
подменяют расходы P&L.

## Установка

1. Сделайте резервную копию конфигурации 1С.
2. Распакуйте `RevoraExtensionReady-v17-operations.zip`.
3. В Конфигураторе откройте расширение `Revora`.
4. Выберите **Конфигурация → Загрузить конфигурацию из файлов…** и укажите
   папку, содержащую `Configuration.xml` из архива.
5. Выполните **Проверка модулей**, затем обновите конфигурацию базы данных.
6. После завершения автодеплоя backend выполните пробную синхронизацию за
   1–2 дня и проверьте страницы «Врачи», «Продажи» и «Прибыли и убытки».

Повторная отправка тех же пациентов, врачей, записей и затрат обновляет те же
строки по стабильным GUID и не создает дублей.
