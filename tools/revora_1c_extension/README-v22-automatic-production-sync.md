# Revora 2.2 — финальная автоматическая синхронизация

- Регламентное задание включено в расширении.
- Рабочий интервал — каждые 30 минут (задаётся один раз в расписании 1С).
- Текущий день отправляет пациентов, записи и другие операционные данные.
- Официальные дневные финансовые итоги отправляются только за закрытые дни,
  поэтому отсутствие строки `ИТОГО` в течение дня не считается аварией.
- При любой ошибке источника, отправки или отклонённой записи контрольная
  точка не сдвигается; следующий запуск безопасно повторяет окно с перекрытием.
- Повторная отправка идемпотентна, параллельный запуск защищён арендой.

После установки завершите активные сеансы 1С, откройте расписание задания
`Revora: почасовая синхронизация` и задайте повтор каждые `1800` секунд.
