# Revora 1.9.1 — исправление чтения полей комплексного прогона

Полный прогон v19.0 установил точную ошибку обеих стратегий: объект поля набора
СКД не имеет свойства `Поле`. v19.1 читает штатное свойство `ПутьКДанным`.

Все эксперименты v19.0 сохранены в одном запуске: исходная и детальная структуры
СКД, обычный и привилегированный запросы, официальный экранный результат,
обезличенный профиль и строгая сверка трёх итогов. Экспериментальные данные не
принимаются без полного совпадения и наличия врача. Почасовая синхронизация
выключена.

## Проверка

1. Обновить расширение из `RevoraExtensionReady-v19.1-one-pass-sync.zip`.
2. Выполнить `Проверка модулей`.
3. Синхронизировать `04.08.2026–05.08.2026`.
4. Скопировать сюда весь текст результата.

Годовую синхронизацию пока не запускать.
