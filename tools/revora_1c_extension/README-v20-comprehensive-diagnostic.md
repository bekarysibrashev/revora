# Revora 2.0 — один комплексный прогон

Эта сборка заменяет цепочку диагностических версий одним контрольным запуском.
Она проверяет не только зарплату или начисленную выручку, а все семь
контрольных источников и четыре операционных потока.

В одном результате отображаются:

- начисленная выручка, услуги, скидки и разрезы по врачам, филиалам
  и специализациям;
- фактические оплаты и их разрезы;
- отдельный отчет выручки по врачам;
- начисленная зарплата;
- закупки и расходы;
- пациенты и новые пациенты;
- записи, приемы, отмены, неявки, переносы и суммы из журнала записи;
- отправленные пациенты, врачи, специальности, записи и расходы;
- число отклоненных сервером записей и точные технические ошибки каждого
  источника;
- для каждого metric_code — значение clinic, количество и сумма каждого
  доступного разреза, а также `[OK]` или `[РАСХОЖДЕНИЕ]`;
- вся расширенная диагностика официального отчета выручки из v19.0–v19.2,
  включая автоматическое исключение до 20 отсутствующих полей СКД.

Ошибка одного второстепенного источника больше не останавливает проверку
остальных. Произвольные подписи измерений в комплексной части не выводятся,
поэтому в ней нет ФИО пациентов или врачей.

## Один контрольный запуск

1. Обновить расширение из `RevoraExtensionReady-v20-comprehensive-diagnostic.zip`.
2. Выполнить `Проверка модулей`.
3. Синхронизировать `04.08.2026–05.08.2026` один раз.
4. В поле результата нажать `Ctrl+A`, `Ctrl+C` и прислать весь текст, а не
   серию скриншотов.

После разбора этого единственного отчета выпускается чистая production-сборка
без объемной диагностики. Годовую загрузку до нее не запускать. Регламентная
почасовая синхронизация в этой сборке остается выключенной.
