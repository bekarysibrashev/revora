# Revora 1C Extension v18.2

`RevoraExtensionReady-v18.2-complete-sync.zip`

Исправляет ошибку импорта регламентного задания из v18.1:

```text
Ссылка на неизвестный метод — РвОбменСервер.ВыполнитьРегламентнуюСинхронизацию
Имя метода должно быть задано
```

Причина: в XML задания использовалось неквалифицированное имя метода.
В v18.2 указано полное имя, требуемое форматом выгрузки 1С:

```text
CommonModule.РвОбменСервер.ВыполнитьРегламентнуюСинхронизацию
```

Остальная логика v18.1 не изменена. Регламентное задание по-прежнему
поставляется выключенным (`Use=false`).

## Установка

1. В Конфигураторе открыть расширение `Revora`.
2. Выбрать `Конфигурация → Загрузить конфигурацию из файлов…` для открытого
   расширения и указать распакованную папку v18.2, как при предыдущем обновлении.
3. Убедиться, что окно загрузки больше не показывает ошибку неизвестного метода.
4. Выполнить `Конфигурация → Проверка модулей`.
5. Применить изменения и проверить короткую ручную синхронизацию.
6. Почасовое задание включать только после успешной ручной проверки.

Статические проверки ZIP/XML/UTF-8 и баланса BSL не заменяют проверку модулей
в реальном Конфигураторе.
