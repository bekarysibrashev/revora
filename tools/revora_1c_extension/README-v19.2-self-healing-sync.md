# Revora 1.9.2 — самовосстановление полей СКД

v19.1 доказала две вещи: RLS не влияет на результат, а основной запрос даёт
промежуточный итог экранного отчёта. Детальная стратегия остановилась на
устаревшем поле `ЗубнойТехник`, объявленном в схеме, но отсутствующем в
фактическом результате запроса.

v19.2 не требует отдельной сборки для каждого следующего устаревшего поля. При
точной ошибке `Поле не найдено "Имя"` она исключает только названное платформой
поле и повторяет построение, максимум 20 раз. Любая другая ошибка не скрывается.
Список исключений показывается в результате.

Обычная и привилегированная выборки, исходная и детальная СКД, экранный профиль
и строгая сверка трёх итогов выполняются за один запуск. Данные принимаются
только при полном совпадении и наличии врача. Почасовая синхронизация выключена.

## Проверка

1. Обновить расширение из `RevoraExtensionReady-v19.2-self-healing-sync.zip`.
2. Выполнить `Проверка модулей`.
3. Синхронизировать `04.08.2026–05.08.2026`.
4. Скопировать сюда весь текст результата.

Годовую синхронизацию пока не запускать.
